# Reference screens

Our own designs, exported from the product design file. They show where the
audit's findings land in this product; they are not competitor material.

| File | Screen | Requirements it specifies |
| ---- | ------ | ------------------------- |
| `permission-rules-list.png` | Metadata-based content permission rules — the rule list | `PRM-4`–`PRM-12`: enabled toggle, Grant/Deny type, operation scope as a set, assigned roles, plain-language predicate summary, last modified. Roles in the rail show "Source: Identity Provider" — `PRM-1`. |
| `retention-period-configuration.png` | Retention policy configuration | `RET-1`–`RET-9`: policy as an object with draft, active and retired states; period as value plus unit; a named start event; policies attached to document types. |
| `zip-export-bulk-operations.png` | ZIP export and bulk operations | `BLK-1`–`BLK-13`: row and master checkboxes, "select all filtered results" as a distinct action, an inline selection-limit message, bulk delete with a reason, metadata export format choice, and a bulk-operations panel that outlives the toast. |
